# Expenses Tracker System

## 📌 Overview

The **Expenses Tracker System** is a simple desktop application designed to help users record, track, and manage their daily expenses. This project focuses on simplicity, usability, and practicality, making it beginner-friendly while still being useful for real-life scenarios.

The system allows users to input expenses, view records, and store data securely using a local database.

---

## 🎯 Purpose of the Project

* Practice **Python programming**
* Apply **learning-while-building** approach
* Understand how desktop applications work
* Learn how to use a **local database** for data storage
* Build a real, usable system instead of just small exercises

---

## 🛠️ Features

* Add new expense records
* Store expenses in a local database (SQLite)
* Simple and clean GUI design
* Beginner-friendly layout
* Data is saved permanently on the user’s computer

---

## 💻 Technologies Used

* **Python**
* **Tkinter** (GUI)
* **SQLite3** (Database)
* **OS module** (for file and folder management)

## 🚀 How to Run the Project

1. Make sure Python is installed on your computer
2. Clone or download the project
3. Open the project folder
4. Run the application:

```bash
python main.py
```
